# 마이페이지 기능 구현

요청: 예매 내역의 내 데이터를 제거하고 준비 중인 메뉴를 실제 기능으로 연결한다.

기존 Vue/Pinia와 FastAPI/SQLAlchemy를 유지한다. 찜과 탈퇴는 기존 API를 재사용하고,
알림 설정은 계정별 DB에 저장한다. MBTI 리포트는 실제 기록을 집계하며 가상 통계는 표시하지 않는다.
알림 전달 범위는 마이페이지 내 알림 목록이다. 외부 메일·문자 발송은 현재 인프라에 없다.

1. 개인 기록·같은 MBTI 찜 집계, 알림 설정 저장·계정 격리·삭제·예정 공연 필터 테스트를 작성한다.
2. 리포트와 알림 API의 Pydantic 계약, 알림 설정 테이블과 Alembic 마이그레이션을 추가한다.
3. 예매 패널에서 데이터 관리와 찜을 제거하고 독립 찜 패널로 이동한다. 홈과 같은 서버 찜 상태를 사용한다.
4. 리포트, 알림 설정 및 알림 목록, 확인 절차가 있는 회원 탈퇴 패널을 연결한다.
5. 전체 백엔드 테스트, 프런트 빌드, 마이그레이션과 API 호출을 검증한다.

검토 초점: 취소 예매 제외, 다른 계정의 기록 노출 방지, 빈 리포트, 중복 하트 클릭,
저장 오류 표시, 탈퇴 후 인증·연관 데이터 삭제, 새로고침 후 설정 유지.
