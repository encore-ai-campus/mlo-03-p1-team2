| 192.168.0.176 | 2.0 | 5.74 | 15.38 | 4.89 | 3.10 |
| 192.168.0.177 | 2.0 | 5.74 | 2.92 | 5.15 | 2.99 |
| 192.168.0.178 | 2.0 | 5.74 | 3.66 | 5.14 | 3.00 |

- MariaDB `192.168.0.171:9104`: 최대 동시 연결 45개. 관측된 `max_connections`는 151개, InnoDB 버퍼 풀은 128MiB다.
- FastAPI의 실제 worker 수와 배포 DB 연결 풀 설정은 별도 확인하지 못했다. 제안 문서의 값을 실측값으로 사용하지 않았다.

## 부하 발생기 관측

- 논리 프로세서: 16개.
- Python 발생기 최대 관측 작업 메모리: 143.6MiB.
- 표본 사이 CPU 시간 증가량 기준 최대 CPU 사용률: 24.37% (논리 코어 1개=100% 기준). 표본 사이 순간 포화는 판정할 수 없다.
- 네트워크 누적 송수신 바이트도 원시 표본에 보존했다. 호스트의 다른 프로그램 트래픽이 포함될 수 있어 API 트래픽만의 사용률로 해석하지 않는다.
