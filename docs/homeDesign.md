# 홈 화면 디자인 기준

2026-11-04 홈 시연판에서 정리한 디자인 기준값입니다.
현재 구현은 `frontend/src/assets/styles.css`, `frontend/src/views/HomeView.vue`,
`frontend/src/components/`의 홈 컴포넌트와 `frontend/index.html`에서 관리합니다.
아래 수치는 당시 기준을 보존한 것이며 이번 문서 정리에서 현재 CSS와 전 항목을
재측정하지 않았습니다. 화면·스타일 수정 시 실제 적용값과 대조해 갱신합니다.
이 파일 자체가 CSS 값을 강제하지는 않습니다. 실행·구조 설명은 [frontend.md](frontend.md)를 따릅니다.

## 적용 범위와 화면 구간

- 공통 헤더, 홈 배너, 공연 목록, MBTI 배너, 랭킹, 하단 서비스 안내를 대상으로 합니다.
- 아래 표의 숫자 단위는 별도 표기가 없으면 `px`입니다.
- PC: 화면 너비 `1000px 초과`.
- 태블릿: `760px 초과 ~ 1000px 이하`.
- 모바일: `760px 이하`.
- 표의 `동일`은 바로 왼쪽 구간과 같은 값을 뜻합니다.
- 너비와 높이는 `box-sizing: border-box` 기준이며, 고정 너비가 명시되지 않은 요소는 가용 공간에 따라 변합니다.

## 이후 수정 시 참고

1. 기능·데이터만 수정할 때는 위 글자 크기, 너비, 간격, 배너 비율을 유지합니다.
2. 디자인 수치를 의도적으로 바꾸면 `frontend/src/assets/styles.css` 또는 해당 컴포넌트 스타일과 이 문서의 해당 항목을 함께 갱신합니다.
3. CSS 맨 아래에는 헤더·메뉴·배너 너비 및 카테고리 버튼 재정의가 있습니다. 앞부분 선언만 보고 값을 판단하지 않습니다.
4. 공통 클래스인 `.wrap`, `.section`, `.poster`, `.tag` 등을 바꾸면 다른 화면도 영향을 받을 수 있습니다.
5. 화면 확인은 PC 1440px, 태블릿 900px, 모바일 390px 및 경계 760/761px, 1000/1001px에서 진행합니다. 브라우저 배율 100%와 폰트 로딩 상태를 맞춥니다.
6. 이 문서는 기존 디자인 수치의 기준표입니다. 폰트 로딩, 콘텐츠 길이, 브라우저 배율에 따른 줄바꿈까지 고정하는 장치는 아닙니다.
